# Investigating Variational Quantum Classifier Feature Maps Across Dataset Geometries

Quantum feature maps determine how classical input data is encoded into quantum bits (qubits) so that quantum algorithms can be carried out on it. A variational quantum classifier (VQC) is a hybrid quantum machine learning architecture which uses feature maps to encode classical data into quantum states before running classical machine learning algorithms on the states. The primary research goal of the present study was to investigate how varying feature map encodings affect VQC performance across different dataset geometries and levels of noise in the data. The objective was to attempt to identify a mathematical connection between the formulas defining the feature map’s interaction angle encodings and geometrical patterns within the datasets. Three established baseline feature maps were compared with four literature-derived maps as well as two original maps. Each of the feature maps was trained for 25 repetitions across 7 synthetically-generated, binary classification datasets and 11 levels of noise per dataset. One key result was that feature map encodings with quantum entanglement features generally achieved higher mean accuracy than those without. The overall best-performing feature map by mean accuracy across all datasets and noise levels was F6, and the worst was Angle. The F6 map performed exceedingly well on the Moons, Circles, and Spiral datasets, which shared certain symmetrical similarities with the F6 interaction-angle formula. The original maps, M1 and M2, ranked third and second, respectively, in overall mean evaluation accuracy. M1 aimed to combine a radial and angular term, but increasing mathematical elaborateness proved not to guarantee better accuracy. M2, which introduced discrete parts to the formula (contrasting with the continuity of the other maps), achieved the highest accuracy on Sectors. The two-qubit VQC was simulated through PennyLane in Python.
